# Лабораторная работа №5

## Выполненные требования

- Тема «Музыкант и звукорежиссёр» (вариант №9): интерактивный плейлист треков в разделе «Плейлист».
- Поиск элементов через `getElementById` (кнопки), `querySelector` (контейнеры) и `querySelectorAll` (треки при очистке плейлиста).
- Кнопка «Добавить трек»: через `prompt` запрашиваются название и длительность (формат мин:сек), через `createElement` создаётся `<li>` с названием, длительностью, чекбоксом «Избранное» и кнопкой «Удалить»; элемент добавляется через `appendChild`. Ввод проверяется, отмена и пустые значения не добавляют трек.
- Чекбокс «Избранное» меняет класс `favorite` у трека, кнопка «Удалить» удаляет именно свой трек через `remove()`.
- Кнопка «Очистить плейлист»: все треки находятся через `querySelectorAll` и удаляются циклом; если плейлист пуст, выводится `alert` «Плейлист уже пуст» и сообщение в консоль.
- Кнопка «Скрыть плейлист» добавляет и убирает класс `hidden` у контейнера; текст кнопки и атрибут `aria-expanded` обновляются.
- Переключение светлой и тёмной темы по кнопке: классы `theme-light` и `theme-dark` у `<body>` меняют CSS-переменные.
- Обработка ошибок: перед запуском проверяется существование всех нужных элементов; если элемент не найден, в консоль выводится «Элемент не найден: [селектор]» и скрипт плейлиста не выполняется.
- Состояние (треки, отметки «Избранное» и выбранная тема) сохраняется в `localStorage` при каждом изменении и восстанавливается при загрузке страницы; повреждённые данные игнорируются.

## Запуск

Откройте файл `index.html` в браузере. Плейлист находится в разделе «Плейлист», кнопка смены темы расположена в шапке страницы. После перезагрузки страницы треки, избранное и тема восстанавливаются из `localStorage`.
